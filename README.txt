TRADELOCK X — VERCEL + WINDOWS SETUP

Two packages are required. Vercel runs the website; your Windows PC runs MT5,
the EA and the connector. This does not run MT5 on Vercel. Your PC must stay
on, awake and online. The chart is TradeLock's candle chart using MT5 data;
it is not an embedded TradingView chart.

1. WINDOWS CONNECTOR
Back up your current TradeLock folder. Extract Windows_Connector.zip into that
folder, replacing program files. No saved configuration/password files are
included, so keep your existing configuration. For a fresh install, install
64-bit Python 3.11/3.12 and MT5, then run START_BROWSER.bat.
Open http://127.0.0.1:8000 and sign in. Configure BOTH administrator passwords
and broker symbols locally before enabling remote access. Keep your existing
TradeLock EA attached to ONE MT5 chart with Algo Trading enabled. For a fresh
install, compile TradeLock_X_V3_EA.mq5 in MetaEditor and attach it first.
Run CONFIGURE_REMOTE.bat. Copy the generated connector key somewhere private.
Run RESTART_BROWSER.bat. The engine should announce connector port 8001.

2. HTTPS CONNECTION — QUICK TEST
Download Windows cloudflared from:
https://developers.cloudflare.com/tunnel/downloads/
Rename the downloaded executable cloudflared.exe and place it in your
TradeLock folder (or install on PATH). Run START_TUNNEL.bat. Keep its window
open. Copy its HTTPS URL, such as https://random-name.trycloudflare.com.
This must tunnel ONLY http://127.0.0.1:8001, never port 8000.
Quick tunnels are for testing, have no uptime guarantee, and get a new URL
on every restart. Each new URL requires updating Vercel's environment variable
and redeploying. For ongoing use, create a named Cloudflare Tunnel with a
stable hostname on your domain, mapping to http://127.0.0.1:8001:
https://developers.cloudflare.com/tunnel/get-started/
Keep the connector secret header protection in either setup.

3. GITHUB
Extract TradeLock_Vercel_Website.zip. Create a private GitHub repository.
Upload the CONTENTS of the extracted folder: api/, public/, test/,
package.json, vercel.json and README.txt. These must be at the repository root.
Do not upload the Windows folder, MT5 credentials, configuration files,
tradelock_bridge.json or any real secrets. GitHub browser folder upload can
be done by dragging the extracted folders/files into Add file > Upload files.

4. VERCEL
Sign in at https://vercel.com and choose Add New > Project.
Import the GitHub repository. Use Framework Preset: Other.
Root Directory: repository root. Build Command: leave empty.
Output Directory: public. The included vercel.json supplies this setting.
Add these SERVER environment variables for Production (also Preview if you
want preview deployments to connect):
TRADELOCK_ENGINE_URL = the HTTPS tunnel origin, with no additional path
TRADELOCK_BRIDGE_SECRET = the key generated by CONFIGURE_REMOTE.bat
Do not use NEXT_PUBLIC_ or VITE_ prefixes. Click Deploy.
If you change environment variables later, redeploy for changes to take effect.
Open your Vercel website and sign in with your existing software password.
Signing in locally or remotely replaces the previous session.

5. VERIFY BEFORE USING LIVE
Keep MT5, EA, browser engine and tunnel running. Check the website says
DEMO CONNECTED and EA MANAGER READY. Confirm quotes and candles update.
Check Admin settings, pips/price synchronization and a small DEMO pending
order/cancellation. Verify the order and broker SL in MT5. Test the profit
ladder on demo. This package has automated proxy, connector and engine checks;
actual Windows MT5 trading and Vercel deployment still need your demo test.
If an order times out, inspect positions/history before sending another order.
The website blocks new orders without the EA heartbeat, but closing MT5 stops
the local EA from managing the ladder. Keep the trading PC running.

TROUBLESHOOTING
Connector unavailable: check PC, engine, MT5 and tunnel; update changed URL.
Keys do not match: copy the same key into Vercel and redeploy.
Complete setup locally: configure software login and BOTH admins on port 8000.
Port already in use: stop the old engine and run RESTART_BROWSER.bat.
Wrong tunnel service: point Cloudflare to port 8001, not 8000.
Settings/passwords remain in your Windows configuration, not on Vercel.
Password recovery still requires both admin passwords. Keep them safely.
A website does not prevent opening MT5 directly on Windows; Windows access
restrictions are a separate setup. This package retains existing app behavior.
